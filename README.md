Your teacher wrote 'digest the material' on the board, so I did. Chapter four is in my stomach now, and I can confirm it was definitely maths. This program writes that one excuse — the dog's own account of eating the homework — to `/output/entry.txt` for the judge. One line, 142 characters, with the twist saved for the very last words: the dog followed the teacher's instruction to the letter, and is quietly proud of it.
